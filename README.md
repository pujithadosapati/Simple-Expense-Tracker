## Simple Expense Tracker
## Project Description
The Simple Expense Tracker is a Python-based application that helps users record and manage their daily expenses. It stores expense details in a CSV file and generates spending reports.
## Features
- Add new expenses.
- View all expense records.
- Calculate total spending.
- Generate category-wise spending summaries.
- Generate monthly spending reports.
- Validate dates and expense amounts.
- Store records using CSV file handling.
## Technologies Used
- Python
- CSV (Comma-Separated Values)
## Python Concepts Used
- Functions
- Lists and Dictionaries
- Loops and Conditional Statements
- File Handling
- Exception Handling
- CSV Module
## How to Run
1. Open Programiz Online Python Compiler.
2. Copy and paste the Python source code.
3. Click the Run button.
4. Select an option from the menu.
5. Enter the required expense details.
6. View your expense reports.
CSV File Structure
The application stores the following information:
- Date
- Category
- Description
- Amount
  ## Expected Output
The application displays all expenses, total spending, category-wise summaries, and monthly reports.
